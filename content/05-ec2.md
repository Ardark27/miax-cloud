# Amazon EC2

Máquinas virtuales en la nube.

---

# Qué nos da EC2

| Pieza | Qué es |
|---|---|
| **Instancia** | La máquina virtual |
| **AMI** | Plantilla con sistema operativo y software |
| **Tipo de instancia** | Combinación de CPU, memoria y red |
| **Par de claves** | Acceso seguro por SSH |
| **EBS** | Disco persistente |
| **Grupo de seguridad** | Cortafuegos de la instancia |

---

# Opciones de compra

| Opción | Compromiso | Cuándo usarla |
|---|---|---|
| **Bajo demanda** | Ninguno, por segundos | Desarrollo, cargas puntuales |
| **Savings Plans** | Gasto por hora, 1 o 3 años | Uso estable |
| **Instancias reservadas** | Configuración concreta, 1 o 3 años | Uso muy predecible |
| **Spot** | Ninguno; AWS puede reclamarla | Procesos interrumpibles, entrenar modelos |

# Tipos de instancia

Se nombran así: `t3.micro` → familia `t`, generación `3`, tamaño `micro`.

| Familia | Enfocada a |
|---|---|
| **T** | Uso general con ráfagas de CPU |
| **M** | Uso general equilibrado |
| **C** | Cómputo |
| **R** | Memoria |
| **P** | GPU para IA: P4 (A100), P5 (H100/H200), P6 (Blackwell) |
| **G** | GPU para gráficos e inferencia |

::: novedad Capa gratuita
Para cuentas nuevas: `t3.micro`, `t3.small`, `t4g.micro`, `t4g.small`, `c7i-flex.large` y `m7i-flex.large`. Usaremos **`t3.micro`**.
:::

Las instancias con GPU requieren pedir un aumento de cuota. [Lista completa de tipos](https://aws.amazon.com/es/ec2/instance-types/).

# Amazon Linux 2023

- Una **AMI** define lo que trae la máquina al arrancar.
- Puedes crear tus AMI para no reinstalar software.
- Para IA existen las [AWS Deep Learning AMI](https://aws.amazon.com/es/machine-learning/amis/), con controladores NVIDIA CUDA y librerías como PyTorch.

# Tipos de almacenamiento

| Tipo | Servicio | Se comporta como |
|---|---|---|
| **Bloque** | EBS | Un disco duro conectado a una máquina |
| **Fichero** | EFS | Una carpeta de red compartida |
| **Objeto** | S3 | Un almacén de ficheros accesible por API |

- El disco raíz de las instancias suele ser un volumen **EBS**, y hoy `gp3` es el tipo por defecto.
- Se pueden hacer **snapshots** como copia de seguridad.
- El **almacén de instancia** es un disco temporal: se pierde al detener la máquina.

# Acceso seguro

**Par de claves**

- Linux no usa contraseña: AWS guarda la clave pública y tú la privada.
- Formato `.pem` para OpenSSH, también en Windows 10 y 11.
- Formato `.ppk` solo si usas PuTTY.

**Grupo de seguridad**

- Cortafuegos por instancia: decide qué puertos y orígenes entran.
- Permite SSH (22) solo desde **tu IP**, no desde `0.0.0.0/0`.

# Demo: lanzar una instancia

::: demo Lanzar EC2
1. Abre [Lanzar instancia](aws:ec2-launch).
2. **Name**: `miax-{{alias}}`.
3. **AMI**: Amazon Linux 2023.
4. **Instance type**: `t3.micro`.
5. **Key pair**: **Create new key pair**, tipo RSA o ED25519, formato `.pem`. Guarda el fichero.
6. **Network settings**: permite SSH desde **My IP**.
7. Pulsa **Launch instance**.
8. Abre [Instancias](aws:ec2-instances) y espera a que el estado pase a **Running**.
:::

# Conexión desde el navegador

::: demo EC2 Instance Connect
1. En [Instancias](aws:ec2-instances), selecciona la tuya y pulsa **Connect**.
2. Elige la pestaña **EC2 Instance Connect** y pulsa **Connect**.
3. Ejecuta `cat /etc/os-release` y `df -h`.
:::

::: nota Si no conecta
Instance Connect entra por el puerto 22 desde los rangos de IP de AWS. Si limitaste el grupo de seguridad a tu IP, usa SSH (siguiente lección) o Session Manager.
:::

# Direcciones IP

| Tipo | Se conserva al detener | Coste |
|---|---|---|
| **Privada** | Sí | Sin coste |
| **Pública** | No, cambia al arrancar | 0,005 $/hora |
| **Elástica** | Sí, hasta que la liberes | 0,005 $/hora |

::: nota 
Toda IPv4 pública tiene coste, incluso asociada a una instancia en marcha.
:::

Revisa las tuyas en [IP elásticas](aws:ec2-eip).

---

# IP elástica

Una **IP pública fija** que reservas en tu cuenta y asocias a una instancia.

- **Para qué**: que la dirección no cambie al detener y arrancar la máquina.
- **Sentido del tráfico**: entrada y salida. Desde Internet se llega a la instancia si el grupo de seguridad lo permite.
- **Coste**: 0,005 $/hora, también sin asociar. Libérala cuando no la uses.

# NAT gateway

Da **salida a Internet** a las máquinas de una subred privada, que no tienen IP pública.

::: flow
EC2 :: subred privada -> NAT gateway :: subred pública, con IP elástica -> Internet Gateway -> Internet
:::

- **Para qué**: instalar actualizaciones o llamar a API externas sin exponer la máquina.
- **Sentido del tráfico**: solo salida. Desde Internet no se puede iniciar una conexión hacia la máquina.
- **Coste**: desde 0,045 $/hora y 0,045 $/GB, según la región. Son más de 30 $ al mes aunque no pase tráfico.

# Detener o terminar

| Acción | Cómputo | Disco EBS | Datos |
|---|---|---|---|
| **Stop** | No se paga | Se sigue pagando | Se conservan |
| **Terminate** | No se paga | Se borra por defecto | Se pierden |

::: limpieza Terminar una instancia
1. En [Instancias](aws:ec2-instances), selecciona la máquina.
2. **Instance state** → **Terminate (delete) instance** y confirma.
3. Revisa que no queden [volúmenes](aws:ec2-volumes) ni [IP elásticas](aws:ec2-eip).
:::

# Ejercicio

::: ejercicio Gana 20 $ con EC2 y crea una AMI
1. En la [consola](aws:home), abre **Explore AWS**, filtra por **Earn AWS credits**, elige **Lanzamiento de una instancia mediante EC2** y pulsa **Iniciar actividad**.
2. Sigue sus pasos con Amazon Linux 2023 y `t3.micro` en `{{region}}`, y llama a la instancia `miax-{{alias}}`.
3. Crea un par de claves y guarda el fichero `.pem`: lo usaremos después.
4. **Antes de terminar la instancia**, crea una AMI desde [Actions → Image and templates → Create image](aws:ec2-instances).
5. Busca el resultado en [AMIs](aws:ec2-ami) y espera a que el estado sea **Available**.
:::

# Limpieza: instancia de la actividad

::: limpieza Termina la instancia
1. En [Instancias](aws:ec2-instances), termina `miax-{{alias}}`.
2. Revisa que no queden [volúmenes](aws:ec2-volumes) de esta instancia.
3. Comprueba en **Explore AWS** que la actividad aparece como completada.
:::
