# Amazon S3

Almacenamiento de objetos: el disco duro de los datos en AWS.

---

# Qué es S3

- Almacena cualquier cantidad de datos, accesibles por API.
- Durabilidad diseñada del **99,999999999 %** y disponibilidad del 99,99 % en la clase Standard.
- Datos replicados en al menos tres zonas de disponibilidad (salvo las clases de una sola zona).
- Objetos de hasta **50 TB**.

::: novedad Lo que ha mejorado
- Consistencia fuerte en lectura tras escritura desde 2020.
- Cifrado por defecto en todos los objetos nuevos.
- Los buckets nuevos bloquean el acceso público por defecto.
- El tamaño máximo por objeto pasó de 5 a 50 TB.
:::

---

# Conceptos

| Concepto | Descripción |
|---|---|
| **Bucket** | Contenedor con nombre único global, ubicado en una región |
| **Objeto** | Datos más metadatos |
| **Clave** | Identificador del objeto dentro del bucket |
| **Versión** | Permite conservar el historial de un objeto |

```text
https://miax-{{alias}}-datos.s3.{{region}}.amazonaws.com/market/2018/datos.csv
        └── bucket ────────┘                             └──── clave ─────────┘
```

Las «carpetas» no existen: `market/2018/` es solo parte de la clave, un **prefijo**.

---

# Clases de almacenamiento

| Clase | Para |
|---|---|
| **Standard** | Acceso frecuente |
| **Express One Zone** | Latencia muy baja, una sola zona |
| **Intelligent-Tiering** | Patrón de acceso desconocido |
| **Standard-IA / One Zone-IA** | Acceso poco frecuente |
| **Glacier Instant / Flexible / Deep Archive** | Archivado |

Las reglas de **ciclo de vida** mueven o borran objetos automáticamente. Precios: [S3 pricing](https://aws.amazon.com/es/s3/pricing/).

# Desde la CLI

```bash
aws s3 mb s3://miax-{{alias}}-datos --region {{region}}   # crear
aws s3 ls                                                # listar buckets
aws s3 ls s3://miax-{{alias}}-datos/market/               # listar objetos

aws s3 cp fichero.txt s3://miax-{{alias}}-datos/          # subir
aws s3 cp s3://miax-{{alias}}-datos/fichero.txt ./        # descargar
aws s3 mv s3://miax-{{alias}}-datos/a.txt s3://miax-{{alias}}-datos/b.txt

aws s3 sync ./datos s3://miax-{{alias}}-datos/datos/      # sincronizar carpeta
```

Borrar:

```bash
aws s3 rm s3://miax-{{alias}}-datos/fichero.txt
aws s3 rm s3://miax-{{alias}}-datos/market/ --recursive
aws s3 rb s3://miax-{{alias}}-datos                       # solo si está vacío
```

# Desde Python: boto3

```python
import boto3

s3 = boto3.client("s3", region_name="{{region}}")
bucket = "miax-{{alias}}-datos"

s3.create_bucket(
    Bucket=bucket,
    CreateBucketConfiguration={"LocationConstraint": "{{region}}"},
)
s3.upload_file("market_data.txt", bucket, "market_data.txt")
s3.download_file(bucket, "market_data.txt", "copia.txt")

respuesta = s3.list_objects_v2(Bucket=bucket)
for objeto in respuesta.get("Contents", []):
    print(objeto["Key"], objeto["Size"])
```

`LocationConstraint` es obligatorio salvo en `us-east-1`. `list_objects_v2` devuelve hasta 1.000 claves: usa un paginador si hay más.

Notebook completo: [boto3_s3_example.ipynb](ejemplos/s3/boto3_s3_example.ipynb).

# Credenciales en Python

Orden recomendado:

1. **En AWS**: un **rol de IAM** asociado a la instancia o función. No hay que configurar nada.
2. **En tu ordenador**: `aws login`.

::: aviso Evita las claves en el código
No uses `aws_access_key_id=...` dentro de un programa. Si tienes que usar claves, ponlas en variables de entorno.
:::

::: demo Dar acceso a S3 a una instancia EC2
1. Abre [Roles](aws:iam-roles) → **Create role** → **AWS service** → **EC2**.
2. Añade la política `AmazonS3FullAccess` y llámalo `miax-ec2-s3`.
3. En [Instancias](aws:ec2-instances): **Actions** → **Security** → **Modify IAM role**.
4. Selecciona el rol. En la instancia, comprueba con `aws s3 ls`.
:::

# Desde pandas

Pandas usa `s3fs` para leer y escribir rutas `s3://`:

```bash
pip install pandas s3fs
```

```python
import pandas as pd

bucket = "miax-{{alias}}-datos"
df = pd.read_csv(f"s3://{bucket}/market_data.txt", sep=";")
df = df.loc[:, ["FECHA", "HORA", "VALOR", "PRECIO", "VOLUMEN"]]
df.to_csv(f"s3://{bucket}/market_data_mod.csv", index=False)
```

Con credenciales temporales explícitas, usa `storage_options={"key": ..., "secret": ..., "token": ...}`.
